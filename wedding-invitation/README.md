# Артём & Юлия — сайт-приглашение

Одностраничный сайт-приглашение на свадьбу 19 сентября 2026 года. Чистый
HTML/CSS/JS без сборки и зависимостей — открывается как есть, кладётся на
любой статический хостинг.

Оформление опирается на данные скилла `ui-ux-pro-max` (подбор пары шрифтов,
акценты, чек-лист доступности) и на принципы типографики и вёрстки школы
бюро Горбунова: модульная сетка отступов, единая шкала заголовков, длина
строки под чтение (~62 символа), неразрывные пробелы после однобуквенных
предлогов/союзов, типографское тире, кавычки-«ёлочки».

## Структура

```
wedding-invitation/
  index.html
  css/style.css
  js/main.js
  assets/photos/   ← сюда кладутся реальные фотографии (см. ниже)
```

Разделы страницы (все — из ТЗ): герой с датой и обратным отсчётом →
фотогалерея → программа дня (церемония + банкет) → место проведения с
картой → дресс-код с палитрой → подарки → RSVP (контакт) → закрывающий блок.

## 1. Фотографии

Реальные фото пары уже на месте в `assets/photos/` (`hero.jpg` +
`gallery-1.jpg` … `gallery-6.jpg`) — сжаты под веб и повёрнуты как надо
(в оригиналах с камеры была нужна EXIF-коррекция поворота). Подробное
описание, что на каком фото, и как заменить — в
`assets/photos/README.md`.

## 2. Карта

Точная метка ресторана «Белый рояль» уже встроена через Яндекс.Конструктор
карт (`.map-embed` в секции «Место проведения», `index.html`) — готовый
код виджета, ширина подставлена как `100%` для адаптивности. Менять ничего
не нужно; если понадобится обновить точку — пересоздайте карту на
[yandex.ru/map-constructor](https://yandex.ru/map-constructor/) и замените
`<script src="...">` на новый.

Кнопки «Открыть в Яндекс Картах» рядом с картой пока ведут на текстовый
поиск «ресторан Белый рояль, Курганинск» — при желании замените на прямую
ссылку с точным адресом/координатами.

## 3. RSVP

Сознательно без формы и без бэкенда — раньше здесь стояла форма с полями
и отправкой, но список подтверждений всё равно было некуда вести без
отдельно поднятой базы/таблицы, а форма только создавала иллюзию, что
ответ куда-то дошёл. Вместо этого — простой блок с номером телефона:
гость звонит или пишет напрямую.

**Замените плейсхолдер** `+7 (999) 000-00-00` в `index.html` (секция
`#rsvp`) на настоящий номер — он используется и как подпись, и в ссылке
`tel:`. Там же поправьте строку про WhatsApp/Telegram под свой номер
(или уберите её, если это не единый номер для всех трёх).

Если позже захотите именно список с автосбором ответов — самый простой
вариант без спецхостинга: Google-таблица + Apps Script веб-приложение
(бесплатно, без лимитов). Скажите — подготовлю код и подключу.

## 4. Как проверить и опубликовать

Локально:

```bash
cd wedding-invitation
python3 -m http.server 8080
# открыть http://localhost:8080
```

Опубликовать можно на GitHub Pages (Settings → Pages → папка
`wedding-invitation`), Netlify/Vercel (drag-and-drop папки) или любом
статическом хостинге — сборка не нужна.

При публикации обновите в `index.html`:
- `<meta property="og:image" content="assets/photos/hero.jpg" />` — на
  полный URL (`https://ваш-домен/assets/photos/hero.jpg`), иначе превью
  ссылки в мессенджерах не подтянет картинку.

## Что уже проверено

- Адаптивная вёрстка mobile-first, брейкпоинты 375 / 390 / 412 / 768 / 1024 /
  1440px — без горизонтальной прокрутки на любой ширине.
- iOS/Android: `safe-area-inset-*` под чёлку и жестовую полосу, размер полей
  ввода ≥16px (Safari не зумит при фокусе), все интерактивные элементы
  ≥44×44px, вязкость к `100svh/100dvh` для реальной высоты экрана с учётом
  адресной строки браузера.
- Доступность: семантическая разметка, видимый фокус с клавиатуры,
  `skip-link`, подписи всех полей формы, `aria-live` на статусах формы,
  `prefers-reduced-motion` отключает анимации.
- Прогрессивное появление блоков при прокрутке проверено и на обычной
  прокрутке колесом/тачем, и на резких переходах по якорным ссылкам —
  срабатывает в обоих случаях (двойная защита: `IntersectionObserver` +
  запасная проверка позиции по скроллу).
- Полоса образцов дресс-кода — горизонтальный скролл со сцеплением
  (scroll-snap) на мобильных, ровная раскладка на десктопе; клик/тап по
  образцу копирует HEX в буфер обмена.

Тема сайта единая (тёплая, светлая) и намеренно не подстраивается под
тёмную тему устройства — так у всех гостей приглашение выглядит одинаково.
